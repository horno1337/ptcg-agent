# PTCG ABC agent

Kaggle Simulation agent for the Pokémon TCG AI Battle Challenge. See README.md
for layout, agent contract, and submission steps.

## Rules of the codebase

- `agent/policy.py` is the only file to tune for behavior; keep `safety.py`
  paranoid and dumb — it must never depend on policy internals.
- `agent/obsview.py` / `agent/cards.py` are read-only helpers; no game logic there.
- A crash, invalid action, or timeout is an instant ladder loss. Any change to
  `agent/` must keep `python tests/test_safety.py` green.
- `data/*.json` is generated by `tools/dump_cards.py` from the engine build —
  never hand-edit.
- The official engine source is competition-use-only: it stays OUTSIDE the
  repo (`~/Desktop/ptcg_engine/`), and `engine/` (the .so build output) is
  gitignored. Never commit or push either.
- Local win rates (tools/eval.py) do not predict ladder rank; use them only to
  catch crashes/regressions.

## Submission discipline

The ladder is the only real eval, so every submission is an A/B measurement:

- One change per submission, one commit per change.
- Deck edits (`decks/deck.csv`) and policy edits (`agent/policy.py`) go in
  **separate commits** — never mixed, or results are confounded.
- Tag the hash every time you package:
  `git tag ladder-vN && python tools/build_submission.py` (clean tree only).

## Commands

```bash
tools/build_engine.sh                    # compile engine (ENGINE_SRC to override path)
python tests/test_safety.py              # legality fuzz, no engine needed
python tools/eval.py 30 random           # smoke eval (needs engine build)
python tools/run_local.py random         # one game -> replay.json
python tools/build_submission.py         # package submission.tar.gz
```
